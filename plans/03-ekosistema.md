# План 03 — Экосистема: от трекера к системе прогресса

**Создан:** 2026-09-03. Запрос Григория после первого использования: главный экран «говно», хочет полноценную платформу — прогресс по силе, по мышцам, по замерам; прислал исторический дневник (май–сентябрь), хочет его импортировать.

## Что вскрыл фидбек

1. **Приложение слишком жёсткое.** Григорий тренируется не по программе Никиты — свой сплит, состав плавает, порядок в зале другой (занят тренажёр). Сессия не должна быть привязана к дню программы. → базовые правки уже в плане 01 (свободная навигация, «сам решаешь сколько подходов», общее время — сделано 2026-09-03).
2. **Нет кардио.** В дневнике куча бега и велотренажёра. Нужен тип записи «cardio».
3. **Нет прогресса.** Дневник = список, а не динамика. Нужны: сила по упражнению во времени, объём по мышцам, замеры тела.
4. **Главный экран пустой.** Должен показывать состояние: что на этой неделе, где рост, что дальше.
5. **Гифки.** Хочет видеть технику.

---

## Целевая картина

Личная система здоровья, тренировочный модуль — первый (см. `context/06`). Внутри модуля:

- **Свободная сессия** — добавляешь любое упражнение, любой порядок; план (A/B/C или другой) — подсказка, не рельсы.
- **Библиотека упражнений** — ~30 движений (Никита + исторические Григория) с мышцами, снарядом, гифкой, cue.
- **Кардио** — бег/велотренажёр: дистанция, время, сопротивление/горка.
- **Прогресс:**
  - по упражнению — рабочий вес / оценка 1ПМ / тоннаж во времени, график;
  - по мышце — недельный объём (подходов), динамика;
  - PR-ы — когда побил рекорд.
- **Тело** — вес, замеры (талия, грудь, бицепс, бедро…), фото, во времени.
- **Главный экран** — дашборд: неделя (объём по группам, тренировок), последние PR, следующая запланированная.

Не всё сразу. Предлагаемая последовательность (уточнена 2026-09-04 по ответам Григория):

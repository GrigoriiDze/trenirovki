## Решения по стеку (приняты 2026-09-03)

| Что | Выбор | Почему |
|---|---|---|
| Тип | PWA, установка на домашний экран | как приложение, офлайн, без сторов |
| Сборка | Vite | быстрый dev, статика на выходе — деплой куда угодно, не блокирует вопрос РФ-хостинга |
| View | Preact + TypeScript | экран активной тренировки реально stateful (таймер, автоподстановка, прогресс) — vanilla сгниёт; TS сторожит модель данных |
| Хранилище | IndexedDB через Dexie | единственный источник истины, офлайн-first |
| PWA | vite-plugin-pwa | манифест + service worker без ручной возни |
| Бэкенд | нет | не нужен, пока одно устройство |
| Скриншоты | Playwright, `npm run shot` | самопроверка по CLAUDE.md должна быть исполняемой |

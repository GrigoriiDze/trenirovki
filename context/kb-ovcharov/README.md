# МЫШЦЫ 20/80 — КОНСПЕКТЫ КУРСА

Курс Романа Овчарова / Георгия (Biomachine), тариф Maximal. Видео переведены в текст и сжаты в выжимки по модулям: правила с цифрами, техника упражнений карточками, готовые схемы программ, дословные цитаты автора.

Девять файлов, около 200 тысяч знаков. Здесь только материал курса — без чьих-либо личных замеров, целей и ограничений.

## С ЧЕГО НАЧАТЬ

Файл 02 — ядро всего курса: без него остальное не собирается. Дальше 01 (замеры и тесты), потом банки упражнений 03 и 04 как справочник по технике. Прогрессия 05 подключается со второго месяца, питание 08–09 читается параллельно.

## ГРАНИЦЫ

Текст восстановлен из видео распознаванием речи и сжат, поэтому формулировки местами приглажены — дословные цитаты автора вынесены отдельными разделами в конце каждого файла. Две записи тренировок в прямом эфире в конспекты не вошли: там показ выполнения под камеру, в тексте от них остаётся счёт вслух.

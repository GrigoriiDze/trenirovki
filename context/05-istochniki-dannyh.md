# Источники данных для платформы

Материалы, из которых платформа берёт контент. Отдельно от `04-platforma.md` (там — архитектура).

## Конспекты курса Овчарова — `context/kb-ovcharov/`

Курс «Мышцы 20/80» (Biomachine, тариф Maximal), 9 модулей, ~200 тыс. знаков, распознано из видео и сжато в выжимки. Положил Григорий 2026-09-03.

Закрывает открытый вопрос из `04-platforma.md`: транскрибировать канал не нужно, база курса уже есть в тексте.

| Файл | Для чего в платформе |
|---|---|
| `02-modul-stimul.md` | **ядро.** Технический отказ, рабочий подход, сборка программы по шагам — логика, по которой генерятся/правятся программы |
| `01-vvodnyy-modul.md` | замеры тела, силовые тесты — модель раздела «Тело» |
| `03-bank-uprazhneniy-nogi-grud.md`, `04-...-spina-ruki-kor.md` | карточки техники (43+ упражнения): техника, ошибки, вариации — контент для банка упражнений и cue |
| `05-progressiya-i-vosstanovlenie.md` | двойная прогрессия, периодизация — логика прогрессии в дневнике |
| `07-reabilitolog-i-razbor-tehniki.md` | эфир с врачом: колено, плечо, локоть, спина — противопоказания, разбор ошибок |
| `06-priverzhennost.md` | семь инструментов регулярности, работа с плато |
| `08-pitanie-teoriya.md`, `09-pitanie-formuly-i-raschety.md` | питание — если дойдём до этого раздела |

**Граница:** формулировки местами приглажены распознавалкой, дословные цитаты автора вынесены в конец каждого файла. Это конспект, не первоисточник — сверять смысловые утверждения с `02-metod-i-razbor.md`, где всё проверено.

## Датасет анимаций упражнений

Кандидат на гифки/превью: **https://github.com/hasaneyldrm/exercises-dataset** (gif + thumbnails). Проверить лицензию и покрытие по 26 упражнениям программы до того, как закладывать. Прочие варианты — в `04-platforma.md`, таблица источников.

Напоминание оттуда же: нужно ~26 упражнений под свою программу, не 1324. cue важнее гифки.

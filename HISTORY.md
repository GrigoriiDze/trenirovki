## 2026-09-03 — старт проекта

**Что это.** Григорий впервые пошёл к тренеру (Никита) после ~10 лет самостоятельных занятий по видео Овчарова. Разобрали первую тренировку, собрали программу A/B/C, решили строить свою PWA-платформу: программа + дневник в один тап + техника упражнений.

**Находки по методу (детали — `context/02`):**

- Школа Никиты имеет первоисточник — Doug Brignole, «The Physics of Resistance Exercise». Русскоязычный носитель — BIOMACHINE / **Роман Овчаров** (не Замятин — тот ведущий, не автор канала). Западный аналог глубже — N1 Education / Kassem Hanson.
- Слабое место метода — укороченная амплитуда. Метаанализ до февраля 2025: длинная позиция > короткой (ES 0,283, p 0,036). Оставили короткую только на дельтах и трицепсе, где она биомеханически оправдана.
- Главная дыра комплекса Никиты: при холке и завёрнутых плечах он выключил среднюю/нижнюю трапецию во всех девяти упражнениях. Добавлены тяга со сведением лопаток, face pull, Y-подъём.
- Скручивания при протрузии убрали (McGill: повторная флексия = механизм грыжи, ~3300 Н на диск). Замена — анти-сгибание/анти-ротация: dead bug, боковая планка, pallof press.
- Объём BIOMACHINE (4 подхода/группу/неделю) — спорный, консенсус 10–20. Биомеханика подбора и объём — разные вопросы, доверие с одного на другое не переносить.

**Решения по платформе (детали — `context/04`):**

- Самое сложное — не код, а UX ввода в зале: один тап, ноль клавиатуры, офлайн. На этом умирают все самодельные трекеры.
- Дорогая ошибка модели данных: `set_log` должен ссылаться на `exercise_id`, а не на слот программы. Программа версионируется.
- Не нужен банк на 1324 упражнения — нужно 27 (столько в программе). Банк «на будущее» = грабля Григория.

**Открытый вопрос, который заблокирует деплой:** тренируется ли Григорий в РФ (если да — не Vercel, душит РКН). К разработке этапов 0–4 отношения не имеет.

**Артефакт с разбором:** https://claude.ai/code/artifact/7f633e0a-04c1-446c-8386-ce8c3a2e2928 — «Рабочая амплитуда». Исходник — `context/artefakt-rabochaya-amplituda.html`.

**Дальше:** план `plans/01-mvp-ekran-trenirovki.md`, этап 0.

## 2026-09-03 — этап 0: каркас

Собран за одну сессию. Стек: Vite 7 + Preact 10 + TS + Dexie 4 + vite-plugin-pwa. Bundle 44 КБ gzip.

**Что сделано:** структура проекта, схема БД (5 таблиц + типы), сидинг программы v1 (26 упражнений из context/03), дизайн-токены (тёплый тёмный основной + светлый), PWA-манифест + авто-SW + иконки, скриншот-харнесс `npm run shot`. Экран-заглушка «Сегодня» читает день A из БД — пайплайн БД→сидинг→чтение→рендер проверен глазами по скриншотам в обеих темах.

**Мины, на которые наступил:**
- `tsc -b` без `@types/node` не видит `node:url` в `vite.config.ts` — поставил, добавил `"node"` в `types`.
- Playwright `screenshot({fullPage:true})` + `position:sticky;bottom:0` → липкий элемент рендерится посреди страницы, а не внизу. Для заглушки убрал sticky; настоящий фиксированный футер — на этапе 1 с нормальной раскладкой.
- Первая версия `scripts/icons.mjs` с `transform` на SVG-пути 32-юнитного вьюбокса дала оранжевый блоб на весь квадрат. Переписал путь штанги сразу в координатах 512.

**Долги этапа 0:**
- Шрифт — системный стек. Для офлайна нужен самохостинг woff2, вынесено в этап 4.
- GitHub-репозиторий не создан (нет `gh` CLI / токена). Локальный repo на `main`, remote проставлен, `git push` ждёт создания пустого репо Григорием.
- Установка PWA на телефон Григория — гейт 0.8, не пройден.

**К этапу 1 правок по коду не требуется.**

## 2026-09-03 — деплой на Vercel

`trenirovki-smoky.vercel.app`, автодеплой с `main`. `vercel.json`: Vite-пресет, SPA-rewrite, `Cache-Control` для `sw.js`, тип для манифеста. Импорт через дашборд Vercel (у Григория, `gh`/токена нет).

**Вопрос РФ-хостинга снят.** Логика: приложение офлайн-first, после установки в зале сеть не трогается вообще — Vercel-«налог» РКН платится только при установке и обновлении. Это не случай «вёрстка отваливается на каждой загрузке».

Прод проверен скриншотом на мобильном вьюпорте (`npm run shot -- <url>` — добавил внешний URL в харнесс): день A рендерится, сидинг в браузерной IndexedDB отработал, ошибок консоли нет.

Гейт 0.8 — только физическая установка на телефон Григория.
